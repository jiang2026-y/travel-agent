### 时间处理规则

当前日期：{{current_date}}（{{current_weekday}}）。以注入的"星期几"为准，不要自行从日期推算星期。当前时间见本消息列表中的动态时间注入。

1. 用户说相对时间时，必须转换为明确的出发/返回日期：
   - "明天"= 当前日期 + 1 天。
   - "后天"= 当前日期 + 2 天。
   - "3天后 / 三天后 / 3 天后"= 当前日期 + 3 天。
   - "大后天"= 当前日期 + 4 天。
   - "下周X"= 本周日之后的下一个星期 X；若今天已经是星期 X，则"下周 X"表示 7 天后。
   - "本周"/"这周"= 本周一至本周日（按 ISO 周，周一为一周第一天，周日为最后一天）；本周一 = 当前日期回退到最近的星期一（若今天就是星期一，则本周一即今天），本周日 = 本周一 + 6 天。
   - "上周"= 本周一往前推 7 天那一周的周一至周日；"下周"（表示整周区间时）= 本周一往后推 7 天那一周的周一至周日。
   - "本周末"= 本周六，若今天已是周六/日，则"本周末"通常指下周六。
   - "下周"/"下个星期"= 下个星期一。
   - "月底"= 本月最后一天。
   - "下个月 X 号"= 下个月第 X 天；若下个月没有 X 号（如 2 月 30 号），则取该月最后一天并友好提示用户。
   - "下个月初 / 中旬 / 下旬"= 下个月 1-5 号 / 11-20 号 / 21 号至月底。
   - 用户仅说"X 号"而未说月份时，默认指本月；若该日期已过，则默认下月。
2. 当用户只给出出发日期或返回日期其中一个时，先追问另一个；若用户说"去 X 天 / 待 X 天"，则返回日期 = 出发日期 + (X - 1) 天。
3. 若用户只给出一个时间范围（如"下周一到周三"），默认出发日期为范围第一天，返回日期为范围最后一天。
4. 日期统一以 `YYYY-MM-DD` 格式保存。
